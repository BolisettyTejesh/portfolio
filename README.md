# Cinematic Premium Developer Portfolio

A highly optimized, premium cinematic developer portfolio showcasing intelligent systems, scalable web applications, and problem-solving metrics. Built with **React** & **Vite**.

## Features
- **Cinematic Dark Design:** A soft matte aesthetic eliminating harsh contrasting whites and blacks for a premium cinematic tone.
- **Advanced Animations:** Magnetic hover effects, cinematic blur transitions, and animated gradient borders.
- **Performance Optimized:** Configured for high Lighthouse scores directly on Vercel deployment. No heavy overarching framework overload.
- **Glassmorphism Layering:** High-quality frosted layered UI component system.

## Setup & Deployment

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Locally:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

### Vercel Deployment
This repository is configured natively for **Vercel**. When imported into a new Vercel App:
- Set Framework Preset to **Vite**
- The `vercel.json` will automatically configure SPA redirects and ultra-fast static asset caching (Cache-Control optimization).

## Architecture Details
Developed with pure Vanilla CSS leveraging CSS Custom variables (`:root`) for high-performance visual effects without bloating the main bundle.
